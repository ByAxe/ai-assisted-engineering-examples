# Shared Language Outline

## Core Theses

- `chat`, `edit`, and `agent` are different disciplines.
- AI engineering starts when the loop is `plan -> act -> verify -> correct`.
- Feedback loop quality matters more than model choice.
- Steering is layered context architecture.
- `AGENTS.md` holds invariants only.
- Context engineering is broader than prompt engineering.
- Readiness is diagnosed through rehearsal, not through abstract audit.

## Steering Layers

1. Permanent invariants -> `AGENTS.md`
2. Conditional context -> task-level spec
3. Workflow modules -> skills
4. Automatic triggers -> hooks, pre-commit, CI

Today’s focus is layer 1.
